# Changelog

All notable changes to BlockForge Studio are documented here.

## [2.0.0] — In development

### Added
- Search field for filtering the active block category by block title, summary, category, or type.
- Starter project chooser with Hello World, Calculator, Number Guessing Game, and Python game starter templates.
- Browser-local autosave and an opt-in prompt to restore the most recent draft on startup.
- Version 2 metadata for newly exported `.bforge` project files.
- Project import checks for file size, format/version, valid block types, duplicate IDs, required fields, and excessive nesting.

### Changed
- README now distinguishes the V2 development branch from a stable release.

### Limitations
- Python source is generated and exported; it is not executed in the browser.
- V2 has not yet been fully browser-tested or released. Do not interpret this changelog as a claim that all workflows have passed QA.
